Assignment 1: Hello, World!

Prove that Python, Git, GitHub, and VS Code are installed on your computer and talking to each other by pushing one small change to your own GitHub repository.

This page is a quick map of the assignment. Every command, screenshot, and troubleshooting fix you need is in the full guide.

Open the Full Step-by-Step Guide (PDF) (opens in a new tab)Links to an external site.

> What you'll do

seven steps, in order

  1. Use the CS1430/Assignment1 template to create your own repository.
  2. Clone your new repository to your computer.
  3. Open the cloned folder in VS Code.
  4. Add a print statement with your name below the ASCII art banner.
  5. Run check.py until every line says PASS.
  6. Commit and push your work to your own GitHub repository.
  7. Upload SUBMISSION.txt and answer the reflection questions in Canvas.

> Stuck on a step?

The full guide above has the exact commands, screenshots, and a troubleshooting table for the errors students hit most, including "git is not recognized," backslash warnings in ASCII art, and committing without pushing. Find your step there before asking for help.
